# HopOn Moon (0.7c, experimental)

[Download HopOn-Moon-setup.exe](https://github.com/AshRiverTwT/hopon/raw/moon/builds/HopOn-Moon-setup.exe)

Installs **beside** HopOn, not over it: its own name, install folder, data
(sign-in, cache, settings window state), tray icon and update channel
(`builds/latest.json` on this branch). Both can run at once.

Uses the same chat server as HopOn (0.7 protocol).

**Moon is merged into HopOn 0.8.0.** Moon's in-app update now installs the
regular HopOn (pinned copy: `HopOn-0.8.0-setup.exe`), which updates with every
release from then on.
